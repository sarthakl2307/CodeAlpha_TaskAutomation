
# Task Automation with Python Scripts

## Overview
This project automates the process of moving JPG image files from a source folder to a destination folder using Python.

## Features
- Automatically identifies JPG files.
- Supports both `.jpg` and `.JPG` extensions.
- Creates the destination folder if it does not exist.
- Avoids overwriting files with the same name.
- Reports the number of files moved.

## Technologies Used
- Python
- os module
- shutil module
- File handling

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Place JPG images inside the `Source_Images` folder.
4. Open a terminal in the project directory.
5. Run:

   `python task_automation.py`

## Expected Result
JPG files are moved from `Source_Images` to `Sorted_Images`.
